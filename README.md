# Apple Devices Identifiers

A lightweight Windows desktop application built with WinUI 3 to quickly look up marketing names and internal model identifiers for various Apple devices.
Semi-vibecoded with Gemini 3.6 Flash Extended

---

## Features

* **Comprehensive Database**: Covers iPhone, iPad, iPod, Apple TV, Apple Watch, and HomePod models.
* **Modern UI**: Integrated with a custom immersive title bar.
* **High-DPI Support**: Automatically scales window dimensions based on system DPI settings at launch to prevent UI flickering.

---

## Tech Stack

* **Language / Framework**: C# / .NET 8.0+
* **UI Framework**: WinUI 3 (Windows App SDK)
* **Design System**: Fluent Design (Mica)

---

## Quick Start

### Prerequisites

* Visual Studio versions with `*.slnx` support (with **.NET desktop development** and **Windows application development** workloads installed)
* .NET SDK 8.0
